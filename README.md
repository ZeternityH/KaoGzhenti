# 考公真题 · 行测刷题 App

基于 [ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti) 题库构建的**可安装 PWA 刷题应用**，适配小米手机 / 澎湃 OS（Android 14/15），也可在任意现代浏览器运行。

## 数据规模

| 项目 | 数量 |
|---|---|
| 覆盖年份 | 2016–2026 |
| 试卷套数 | 515 |
| 题目总数 | 58,890 |
| 本地图片 | 39,463 |
| 模块 | 政治理论 / 常识判断 / 言语理解与表达 / 数量关系 / 判断推理 / 资料分析 |

每道题含题干、选项、正确答案、官方解析，图片已本地化，可离线查看。

## App 功能

- **按模块 / 年份 / 地区筛选试卷**，支持名称搜索
- **顺序刷题**：选项即时判定、提交后显示官方解析、答题卡跳转
- **随机练习**：按模块或全混合智能抽题
- **错题本**：答错自动收录，答对自动移除
- **收藏**：星标题目集中复习
- **学习统计**：正确率圆环、各模块正确率、累计作答
- **离线使用**：Service Worker 缓存应用外壳、题库数据与图片
- **安装到桌面**：支持 PWA「添加到主屏幕」，全屏运行，无地址栏

## 在小米手机上使用

1. 用手机浏览器（Chrome / 系统浏览器）打开 **GitHub Pages 地址**（见仓库 Settings → Pages）。
2. 浏览器菜单选择 **「添加到主屏幕」/「安装应用」**。
3. 桌面出现「考公真题」图标，点开即可全屏刷题，首次打开后大多数内容可离线使用。

> 澎湃 OS 基于 Android，完整支持 PWA 安装与 Service Worker 离线缓存。

## 目录结构

```
01-政治理论/ ... 06-资料分析/   原始真题 Markdown（按模块）
90-图片/                        题目图与公式图
index.html / styles.css / app.js / sw.js / manifest.webmanifest   PWA 应用
data/index.json                 题库索引
data/papers/*.json              结构化题目（构建生成，按需加载）
scripts/build-data.mjs          数据构建脚本
```

## 重新构建数据

```bash
node scripts/build-data.mjs
```
